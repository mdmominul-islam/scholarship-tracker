# StudyPath Content Management Guide

## Current architecture
The existing public website is still served by the legacy root `index.html`. The Astro rebuild lives under `src/` on the feature branch and is being prepared for a controlled migration. Existing data files remain at the repository root.

## Update catalogue records
- Bachelor's records: edit `global-bachelor-programmes.json`.
- DAAD catalogue: generated by `scripts/refresh_daad_catalogue.py`; do not hand-edit generated output unless you understand the refresh process.
- Keep each record's official source URL and verification note.
- Use clear values such as `Not confirmed` when information is missing. Never guess fees, deadlines, IELTS requirements or eligibility.

## Add a country, university, course or scholarship
Use the established JSON record structure and provide a stable unique ID, country, institution/programme name, source URL, last verified date, and a note describing anything that still needs confirmation. Validate JSON syntax before committing.

## Publish
Push changes to the selected branch, inspect the preview/build checks, then merge the approved change to `main`. The GitHub Pages workflow builds the Astro site from `main`.

## Local development
Install Node.js 22 or newer, then run:
```powershell
npm install
npm run dev
npm run build
npm run preview
```

## Important
The first version is static. Local shortlist, checklist and planner information stays in the visitor's browser. There is no secure account system, server database, document upload or automatic university application submission.
