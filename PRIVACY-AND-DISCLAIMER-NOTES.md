# Privacy, Security and Content Notes

- StudyPath is a static GitHub Pages website. It has no account system, server database, authentication, document upload, or cloud sync.
- Shortlists, checklists, application plans, deadlines, theme and language preferences use localStorage in the visitor's current browser.
- Visitors must not enter passport numbers, bank details, passwords, medical information or upload private documents.
- Visitors can export and reset local planning data. Clearing browser storage can remove it.
- Feedback opens a mailto draft in the visitor's own email client; the website does not transmit or store feedback.
- Programme and funding data are informational. Each record should be checked against its official source before use.
- Third-party names and marks remain the property of their owners. No affiliation or endorsement is implied.
- No analytics, ad network, paid API, secret key or third-party authentication service is included.
